# Neural Networks
This repository contains laboratory notebooks for my Neural Networks course (Data Science AGH).

This course focuses on the fundamental principles of deep learning through the implementation of core neural network components from scratch. Instead of relying on high-level machine learning frameworks, forward passes, activation functions, and models are built manually to establish a comprehensive understanding of the underlying mathematical mechanics.

1. Lab1: This lab focuses on implementing feed-forward operations, activations, and a Restricted Boltzmann Machine (RBM).
